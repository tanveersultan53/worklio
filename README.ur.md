## ہم نے Worklio کیوں بنایا

ٹیم چیٹ وہ جگہ بن چکی ہے جہاں کمپنیاں اپنا کام کرتی ہیں، پھر بھی زیادہ تر ٹیمیں اسے کرائے پر لیتی ہیں:

- **ہر نئی بھرتی کے ساتھ بل بڑھتا ہے۔** ہوسٹڈ چیٹ عموماً فی شخص، ماہانہ فیس لیتی ہے۔ دس لوگ بڑھائیں تو بل بڑھ جاتا ہے، چاہے باقی کچھ نہ بدلے۔
- **آپ کی گفتگو کسی اور کے سرورز پر ہے۔** فیصلے، کسٹمر کی معلومات، منصوبے اور فائلیں فراہم کنندہ کے ڈیٹا بیس میں، اس کی پالیسیوں اور اس کے علاقے میں رہتی ہیں۔
- **آپ بندھ جاتے ہیں۔** ہسٹری کی حدیں، ایکسپورٹ کی پابندیاں اور مہنگے پلانز تک محدود فیچرز چھوڑنا مشکل بنا دیتے ہیں۔
- **اے آئی شرطوں کے ساتھ آتا ہے۔** اے آئی فیچرز اکثر اضافی قیمت پر آتے ہیں اور آپ کے پیغامات ایسی سروسز کو بھیجتے ہیں جنہیں آپ نے نہیں چنا۔

Worklio اس کا متبادل ہے: ایک مکمل اور جدید ٹیم چیٹ جسے **آپ خود چلاتے ہیں**۔ یہ MIT لائسنس کے تحت ہے، اس لیے آپ اسے ہمیشہ کے لیے مفت استعمال، تبدیل اور بہتر کر سکتے ہیں۔

## خود ہوسٹ کرنے سے کیا بدلتا ہے

| | عام ہوسٹڈ ٹیم چیٹ | Worklio |
|---|---|---|
| **لاگت** | ہر ماہ فی شخص فیس | سافٹ ویئر مفت؛ صرف اپنے سرور کا خرچ |
| **ڈیٹا کہاں رہتا ہے** | فراہم کنندہ کے کلاؤڈ میں | آپ کے سرورز، آپ کا علاقہ، آپ کے بیک اپ |
| **پیغامات کی ہسٹری** | نچلے پلانز میں اکثر محدود | لامحدود؛ ڈیٹا بیس آپ کا ہے |
| **سورس کوڈ** | بند | کھلا (MIT): پڑھیں، جانچیں اور بدلیں |
| **اے آئی** | اضافی قیمت، ماڈل فراہم کنندہ کی مرضی | اپنی کلید: Claude، Gemini یا DeepSeek |
| **چھوڑنا** | ایکسپورٹ اور منتقلی | چھوڑنے کو کچھ نہیں؛ یہ پہلے ہی آپ کا ہے |

**ایک مثال۔** اگر مثال کے طور پر قیمت فی شخص 10 ڈالر ماہانہ ہو تو 50 افراد کی ٹیم سالانہ **6,000 ڈالر** ادا کرتی ہے، اور 100 افراد ہونے پر **12,000 ڈالر**۔ Worklio ایک ہی سرور پر چلتا ہے؛ مثال کے طور پر 40 ڈالر ماہانہ خرچ ہو تو سالانہ **480 ڈالر** بنتے ہیں، چاہے 20 لوگ ہوں یا 200۔ آپ کے اعداد مختلف ہوں گے مگر اصول وہی رہے گا: ہوسٹڈ چیٹ ملازمین کی تعداد کے ساتھ بڑھتی ہے، Worklio آپ کے ہارڈویئر کے ساتھ۔

## آپ کو کیا ملتا ہے

### بات چیت: منظم گفتگو

چینلز، ڈائریکٹ میسجز اور تھریڈز، ری ایکشنز، پولز، پن، بک مارکس، شیڈول شدہ پیغامات، سلیش کمانڈز اور سرچ فلٹرز کے ساتھ۔ کسی بھی پیغام تک فوراً جائیں، چاہے وہ کتنا ہی پرانا ہو۔

![](docs/screenshots/channel.png)

### ملاقات: بجنے والی کالز، جن ہڈلز میں جب چاہیں شامل ہوں

کسی ساتھی کو کال کریں یا چینل میں ہڈل شروع کریں۔ اسکرین شیئر کر کے اس پر ڈرا کریں، ری ایکٹ کریں، ہاتھ اٹھائیں، نوٹس لیں جو تھریڈ میں پہنچ جاتے ہیں، اور وائٹ بورڈ یا بورڈ سب کے سامنے لائیں۔ کالز آپ کی اپنی تنصیب میں LiveKit پر چلتی ہیں۔

![](docs/screenshots/huddle.png)

### تخلیق: چیٹ کے ساتھ دستاویزات، بورڈز اور وائٹ بورڈ

ہر چینل میں ایک دستاویز ہے جسے ٹیم مل کر لائیو لکھتی ہے، ترجیحات، لیبلز، آخری تاریخوں اور ٹیبل ویو والا بورڈ، اور ایک مشترکہ وائٹ بورڈ۔

### پوچھیں: اے آئی جو صرف وہی دیکھتا ہے جو آپ دیکھ سکتے ہیں

اپنے ورک اسپیس کے بارے میں سوال پوچھیں اور حوالوں کے ساتھ جواب پائیں، مصروف چینلز کا خلاصہ لیں، پیغامات دوبارہ لکھیں یا ترجمہ کریں، اور تھریڈز کو کاموں میں بدلیں۔ Worklio AI وہی اجازتیں استعمال کرتا ہے جو سرچ کرتی ہے، اس لیے کبھی ایسا پیغام نہیں دکھاتا جسے کوئی کھول نہ سکے۔ اپنی Claude، Gemini یا DeepSeek کلید استعمال کریں، جو انکرپٹ کر کے محفوظ ہوتی ہے۔

## پانچ منٹ میں خود ہوسٹ کریں

آپ کو Docker (Compose کے ساتھ)، Node.js 22 اور npm کی ضرورت ہے۔

```bash
git clone https://github.com/tanveersultan53/worklio.git && cd worklio
cp .env.example .env
make up
cd frontend && npm install && npm run dev
```

http://localhost:3000 کھولیں، اکاؤنٹ اور ورک اسپیس بنائیں، پھر **ورک اسپیس سیٹنگز ← دعوتیں** سے اپنی ٹیم کو مدعو کریں۔

پروڈکشن میں `docker-compose.prod.yml` سب کچھ ایک سرور پر چلاتا ہے۔ مرحلہ وار رہنمائی [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) میں ہے۔

## آپ کا ڈیٹا، آپ کے اصول

- سب کچھ آپ کے انفراسٹرکچر پر رہتا ہے: پیغامات اور فائلیں آپ کے Postgres اور S3 سے مطابقت رکھنے والے اسٹوریج میں، کالز آپ کے اپنے LiveKit سرور سے۔
- ہر درخواست پر ورک اسپیسز کی علیحدگی سرور پر لاگو ہوتی ہے۔
- مختصر سیشنز، بدلتے ریفریش ٹوکنز اور سائن اِن کوششوں کی حد۔
- اے آئی کلیدیں انکرپٹ ہو کر محفوظ ہوتی ہیں، کبھی لاگ نہیں ہوتیں اور دوبارہ نہیں دکھائی جاتیں۔
